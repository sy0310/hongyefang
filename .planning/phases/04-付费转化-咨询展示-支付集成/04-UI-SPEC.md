| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Feature list bullet gaps, badge internal padding |
| sm | 8px | Price-to-unit gap, tag spacing |
| md | 16px | Card inner padding, grid gap, button-to-bottom spacing |
| lg | 24px | Between feature list items, between card sections, card vertical padding |

| 2xl | 48px | Page top/bottom padding, between major page sections |
| 3xl | 64px | Not used in this phase |

Exceptions:
- Pricing card recommended badge uses `-top-3` (12px = 3 x 4px) to float above card edge — one-time justified exception for visual emphasis.

- First focus: confirm button on open

### 5. ResultCTA — Modified

File: `src/components/result/ResultCTA.tsx` (MODIFIED)

Changes:
- Remove `mailto:` link
- Replace with `router.push('/consult')` via `next/navigation`
- Add tier-based differentiation

```tsx
'use client';

import { Button } from '@/components/ui/Button';
import { useRouter } from 'next/navigation';

interface ResultCTAProps {
  isWishingType: boolean;
  tier: '高度适配' | '中度适配' | '需要准备';
}

export function ResultCTA({ isWishingType, tier }: ResultCTAProps) {
  const router = useRouter();
  const { label, variant } = getCTADetails(isWishingType, tier);

  return (
    <div className="mt-8">
      <Button variant={variant} onClick={() => router.push('/consult')}>
        {label}
      </Button>
    </div>
  );
}

function getCTADetails(isWishingType: boolean, tier: string) {
  if (isWishingType) {
    return { label: '了解更多 →', variant: 'secondary' as const };
  }
  if (tier === '需要准备') {
    return { label: '了解付费咨询服务 →', variant: 'secondary' as const };
  }
  return { label: '查看咨询方案', variant: 'primary' as const };
}
```

The `tier` prop must be passed from `result/page.tsx` — add `tier` to the assessment select query and pass it to `ResultCTA`.

## State Management and Data Flow

### Orders Table (D-08 — Locked)

Migration file: `supabase/migrations/005_create_orders.sql`

| Column | Type | Constraints |
|--------|------|-------------|
| id | uuid | PK, DEFAULT gen_random_uuid() |
| user_id | uuid | NOT NULL, REFERENCES auth.users(id) |
| plan_name | text | NOT NULL |
| amount | integer | NOT NULL (stored as integer, display as formatted) |
| status | text | NOT NULL, DEFAULT 'completed' |
| created_at | timestamptz | DEFAULT now() |

RLS:
- `CREATE POLICY "Users can insert own orders" ON orders FOR INSERT WITH CHECK (auth.uid() = user_id)`
- `CREATE POLICY "Users can view own orders" ON orders FOR SELECT USING (auth.uid() = user_id)`

### Order Creation Flow

```
PricingCard onSelect → PaymentModal opens
  → User clicks "确认支付"
  → Client calls createOrder Server Action:
      INSERT INTO orders (user_id, plan_name, amount, status)
      VALUES (auth_user_id, planName, amount, 'completed')
      RETURNING id
  → On success: redirect("/payment-success?id=${order.id}")
  → On failure: show error inline in modal
```

### ResultCTA Data Flow

```
result/page.tsx (Server Component):
  SELECT score, tier, is_wishing_type, ai_narrative, ...
  → passes tier + isWishingType to ResultCTA

ResultCTA (Client Component):
  receives { tier, isWishingType }
  → determines label + variant via getCTADetails()
  → onClick: router.push('/consult')
```
