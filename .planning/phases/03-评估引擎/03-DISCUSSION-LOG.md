## 评分机制

### 评分主要评估什么？

| Option | Description | Selected |
|--------|-------------|----------|
| 资金 vs 预期回报的比例 | 投入资金 ÷ 预期回报 = 现实感指数 | |
| 四项参数综合加权 | 资金、时间、回报率、投入金额各有权重，加权平均 | ✓ |
| 分层判断：先过滤再评分 | 先用许愿型规则过滤，通过的人再按资金和时间评分 | |

**User's choice:** 四项参数综合加权

---

### 四项参数各自占多大权重？

| Option | Description | Selected |
|--------|-------------|----------|
| 资金最重要 | 弹性资金 40% + 投入金额 30% + 每周时间 20% + 预期回报率 10% | ✓ |
| 均均 25% | 四项平等权重，最简单 | |
| 我来自定义 | 用户自行确定每项权重 | |

**User's choice:** 资金最重要（弹性资金 40% + 投入金额 30% + 时间 20% + 预期回报率 10%）

---

### 适配度分几个等级？

| Option | Description | Selected |
|--------|-------------|----------|
| 3级：高度适配 / 中度适配 / 需要准备 | 简洁，最低级用"需要准备"而非"不适合"，符合 RESULT-02 正面话术要求 | ✓ |
| 4级：优秀 / 良好 / 一般 / 需努力 | 更细层，但需要更精确阈值，用户对分类更敏感 | |
| 2级：适合 / 建议准备 | 最简单，但区分度低 | |

**User's choice:** 3级：高度适配 / 中度适配 / 需要准备

---

### 数字分数用什么范围展示？

| Option | Description | Selected |
|--------|-------------|----------|
| 0–1000分 | 范围大，分层细，视觉上更有差异感 | ✓ |
| 0–100分 | 直观，类似百分制成绩 | |
| 不展示数字，只显示等级标签 | 更简洁，但少了可比较性 | |

**User's choice:** 0–1000分

## 许愿型识别逻辑

### 许愿型判断用哪个公式？

| Option | Description | Selected |
|--------|-------------|----------|
| 回报率过高：预期回报率 > X% | 根据用户填写的"预期年化回报"字段直接判断 | ✓ |
| 投入小 + 预期大：双条件并满 | 投入金额 < X 且预期回报率 > Y%，双条件 | |
| 投入金额 ÷ 预期收益比值 < X | 计算比值，比值越小说明越许愿 | |

**User's choice:** 回报率过高：预期年化回报率 > X%
**Notes:** 用户给出例子：投入200但想赚2000000就是许愿型，意即对高回报率的执念，而非单纯资金少。

---

### 预期回报率超过多少就是许愿型？

| Option | Description | Selected |
|--------|-------------|----------|
| > 500%：投入5个回报来开始识别 | 投入10万期望每年赚50万以上即被识别 | ✓ |
| > 1000%：投入10个回报以上才识别 | 只过滤最极端的情况 | |
| > 300%：投入3个回报即识别 | 过滤面更宽，捕获更多"轻度许愿型" | |
| 我来确定具体数字 | 用户自行决定 | |

**User's choice:** > 500%

---

### 被识别为许愿型后，对最终得分有什么影响？

| Option | Description | Selected |
|--------|-------------|----------|
| 直接强制评为「需要准备」 | 无论加权分多少，许愿型直接进最低等级 | ✓ |
| 尚不强制，但扣减分数，影响最终等级 | 许愿型能因其他因素（资金多、时间多）达到中度适配 | |
| 只添加标记，不影响分数 | 许愿型标签展示但不影响等级，筛选作用几乎为零 | |

**User's choice:** 直接强制评为「需要准备」

## 结果页设计

### 结果页用哪种布局？

| Option | Description | Selected |
|--------|-------------|----------|
| 方案A：大分数居中 | 分数数字最突出，等级标签其次，下方简短建议文字，底部引导按钮 | |
| 方案B：维度拆解卡片 | 顶部综合分+等级，中部四维进度条评估，底部建议+按钮 | ✓ |
| 方案C：画像叙述为主 | AI 生成一段个人画像文字，分数作为辅助，更像体检报告 | |

**User's choice:** 方案B：维度拆解卡片

---

### "需要准备"和许愿型用户的话术调调？

**User's choice（自由回答）：** 许愿型的以最好的语言劝退，适配的用肯定型引导其进入专业人工顾问阶段。

**Notes:** 用户明确区分两类用户的话术方向：许愿型应被温和而明确地劝退，不能用通用的鼓励话术；适配型则应被正面肯定并自然引导进入 Phase 4 的付费咨询环节。

---

### 结果页底部的进入咨询按钮对许愿型用户展示吗？

| Option | Description | Selected |
|--------|-------------|----------|
| 不展示：许愿型看不到进入咨询的入口 | 筛选效果最强，但可能引起用户不满 | |
| 展示但调调不同 | 许愿型看到的是"准备好后可就试"，高度适配看到"立即预约" | ✓ |
| 所有用户展示同样的按钮 | 实现最简单 | |

**User's choice:** 展示但调调不同
