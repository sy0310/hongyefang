    Read the current `src/app/page.tsx` created by create-next-app, then replace it with an auth-aware redirect page.

    ```typescript
    import { createClient } from '@/lib/supabase/server'
    import { redirect } from 'next/navigation'

    export default async function HomePage() {
      const supabase = await createClient()
      const {
        data: { user },
      } = await supabase.auth.getUser()

      if (user) {
        redirect('/dashboard')
      }

      redirect('/login')
    }
    ```

    This is an Async Server Component (uses `await` at top level). It checks the user's session via `getUser()` (which verifies the JWT with Supabase server, not just reading cookie data). Authenticated users go to /dashboard, unauthenticated go to /login.

    Key constraints:
    - Must be a Server Component (async function, no 'use client')
    - Uses `createClient()` from server.ts (not browser client)
    - Uses `getUser()` (not `getSession()`) for security
    - `redirect()` from next/navigation handles the HTTP redirect
  </action>
