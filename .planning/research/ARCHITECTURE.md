# Architecture Research: 创业咨询平台

## Component Boundaries

```
┌─────────────────────────────────────────┐
│              Next.js App                │
│  ┌─────────────┐  ┌──────────────────┐  │
│  │ Landing Page│  │ AI Chat Interface│  │
│  │             │  │ (对话体检)        │  │
│  └─────────────┘  └──────────────────┘  │
│  ┌─────────────┐  ┌──────────────────┐  │
│  │ Result Page │  │ Payment Page     │  │
│  │ (评估结果)   │  │ (支付咨询)       │  │
│  └─────────────┘  └──────────────────┘  │
│  ┌──────────────────────────────────┐   │
│  │ API Routes / Server Actions      │   │
│  │  - /api/chat (AI 对话代理)        │   │
│  │  - /api/payment/create (创建订单) │   │
│  │  - /api/payment/callback (回调)   │   │
│  └──────────────────────────────────┘   │
└─────────────────────────────────────────┘
              │
    ┌─────────┼────────────┐
    ▼         ▼            ▼
┌────────┐ ┌────────┐ ┌─────────────┐
│Supabase│ │ OpenAI │ │ 微信支付/    │
│  Auth   │ │ Claude │ │ 支付宝      │
│  DB     │ │ API    │ │             │
└────────┘ └────────┘ └─────────────┘
```

## Data Flow

1. 用户访问 → Auth (Supabase) → 创建用户记录
2. 用户开始 AI 对话 → API Route → LLM API → 收集参数 → 保存到 DB
3. 对话结束 → AI 评估 → 生成画像 → 保存到 DB → 展示结果页
4. 用户选择咨询套餐 → 创建支付订单 → 跳转支付 → 回调确认 → 转接专员

## Suggested Build Order

1. **基础设置** — Next.js + Supabase 项目搭建 + Auth 接入
2. **用户系统** — 注册/登录、用户资料
3. **AI 对话** — 聊天界面 + AI 代理 + 参数收集逻辑
4. **评估引擎** — 筛选逻辑 + 画像生成
5. **结果页** — 展示评估 + 咨询价格
6. **支付流程** — 微信/支付宝接入 + 回调处理
7. **转接流程** — 支付成功后的专员对接页面

## Key Tables

```sql
users          — 用户基本信息
user_profiles  — AI 评估结果（弹性资金、时间、回报期望等）
consultations  — 咨询订单（套餐、价格、支付状态）
payments       — 支付记录
```
