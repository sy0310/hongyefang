# Features Research: 创业咨询平台

## Table Stakes (必须有)

### Authentication
- 用户注册（手机+验证码、邮箱+密码）
- 用户登录/登出
- Session 管理
- 密码重置

### AI 创业体检
- AI 对话式问卷 — 收集四项核心参数（弹性资金、投入时间、预期回报、投入金额）
- 对话式交互体验 — 非表单式，更像咨询对话
- 对话深度控制 — 追问但不超过 3 轮，避免用户流失
- 评估结果展示 — 适配度评分 + 建议

### 人工咨询转化
- 评估结果页展示咨询价格
- 咨询项目列表 + 价格梯度（2999 - 数万元）
- 支付入口（微信支付 + 支付宝）
- 支付成功后的转接提示页

## Differentiators (竞争优势)

### 用户画像系统
- AI 根据对话生成结构化用户画像
- 自动筛选"许愿型"用户
- 优质客户标记
- 用户画像可视化展示

### 多服务漏斗
- 五级漏斗状态追踪（体检 → 咨询 → DIY → 托管 → 代运营）
- 不同阶段的引导提示

### 行业数据积累
- 行业参考数据展示（装修价格、物料成本等）
- 降低用户决策成本

## Anti-Features (刻意不做)

- DIY 资料交付 — MVP 阶段，后期迭代
- 全权托管/代运营 — 需要运营团队
- 股东匹配拼单 — 需要用户基数
- 服务商入驻 — 需要 C 端验证
- 品牌推荐分成 — 需要项目数据
- 实时聊天/IM — 复杂性高，MVP 不需要
- 移动端原生 App — Web 优先
